## Descripción

Este repositorio contiene los proyectos y ejercicios desarrollados durante las tres rutas de aprendizaje correspondientes a la **Unidad 4**.

Los ejercicios abarcan temas relacionados con el ciclo de vida de las actividades, arquitectura de aplicaciones Android, `ViewModel`, manejo de estado, navegación con Jetpack Compose y diseño de interfaces adaptables.

## Contenido

### Ruta 1 - Componentes de la arquitectura

Ejercicios relacionados con:

- Activity Lifecycle
- ViewModel y estado en Compose
- Dessert Clicker
- Pruebas y manejo del estado

### Ruta 2 - Navegación

Ejercicios relacionados con:

- Navegación entre pantallas con Jetpack Compose
- Aplicación Cupcake
- Práctica de navegación
- Uso de `NavController` y `NavHost`

### Ruta 3 - Diseño adaptable

Ejercicios relacionados con:

- Navegación adaptable
- Aplicación Reply
- Diseño adaptable
- Aplicación Sports
- Proyecto My City
